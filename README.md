# C++ Learning Projects

A public collection of C++ learning projects, organised by programming concept and application domain. Each catalogue entry connects an English project title to its original source and a specific build command.

**Start with:** [Neon Arena](docs/topics/05-games-and-simulation.md), [Australia Budget Planner](docs/topics/04-persistence-and-planning.md), and [Four-Operation Calculator](docs/topics/01-foundations.md).

## Build and explore

Use a C++17-capable compiler. These are independent programs with separate `main` functions: select one source instead of linking every `.cpp` file together. Preserve the surrounding headers when an exercise includes them.

See [build instructions](docs/building.md), [worked examples](docs/examples.md), and the [validation report](docs/validation.md). Existing console messages may be in Italian even where the documentation is in English.

## Engineering perspective

The collection demonstrates learning progression rather than a uniform production framework. Some exercises are unfinished; each catalogue entry identifies material limitations. Successful compilation is reported separately from behaviour checks.

Read [design notes](docs/design-notes.md) for the next steps: explicit state, checked input, clear ownership, and separation of computation from interaction.
